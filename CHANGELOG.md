# Changelog

All notable changes to Semantic Code Highlighter are documented here.

## 0.1.0 — 2026-08-11 (Pre-release)

### Core map

- Added TypeScript/JavaScript AST and statement-region extraction with stable hierarchy.
- Added mutually exclusive, whole-line responsibility backgrounds, overview-ruler markers, hover rationale, and instant visibility toggle.
- Added the conservative zero-credential local classifier and optional OpenAI structured-output provider.

### Trust and convenience

- Added source filtering, first-send disclosure, SecretStorage credentials, content-addressed caching, cancellation, and stale-run protection.
- Added per-file provider/map/lens status, responsibility focus, an on-demand file summary, bounded workspace analysis, project context, and opt-in analyze-on-open.
- Added unknown/low-confidence shielding so a broad parent cannot color an uncertain child line.

### Project

- Added deterministic tests, CI, Extension Development Host fixtures and QA guidance, an installable VSIX build, and a version-controlled LLM wiki.
